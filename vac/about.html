About the project

A college project about shrinking the language gap

LinguaForge was designed and built as an academic exercise: what would a localisation platform look like if it treated glossaries, tone and file structure as first-class citizens?

Project brief

Most translation tools stop at sentence-level output. Real localisation teams care about terminology drift, broken placeholders, tone consistency and review workflows — the unglamorous parts. This project explores that full workflow.

Everything on this site is a front-end concept. The demo runs entirely in the browser with no backend, no API keys and no data collection.

The pipeline

From raw content to market-ready copy

LinguaForge models localisation as a five-stage pipeline. Each stage is inspectable, so reviewers always know why a segment reads the way it does.

01

Ingest & parse

Files are uploaded or pulled from a repo. The parser strips structure down to translatable segments while keeping tags, placeholders and key paths in a sidecar file that travels with the content.

HTMLJSONXLIFFMarkdownDOCXSRT
02

Detect & route

Each segment is language-detected (mixed-language pages are common) and routed to the right model pair. Confidence scores below threshold are queued for human eyes instead of being silently translated.

language IDsegment scoringfallback routing
03

Adapt with context

Translation happens with three constraints attached: the approved glossary, the selected tone profile (neutral, formal, marketing), and neighbouring segments for context — so pronouns and headings stay consistent.

glossary locktone profilewindow context
04

Transcreate where it matters

Segments flagged as marketing copy skip literal translation. The engine proposes rewrites of headlines, slogans and idioms that preserve intent rather than wording, with the original attached for comparison.

intent-preserving rewriteA/B variants
05

QA & ship

Automated checks catch truncated strings, missing placeholders, inconsistent glossary terms and RTL mirror issues. Reviewers edit side-by-side, then exports return to the original file format, ready to compile.

What the concept is built on

The technology choices behind the project design, explained for a technical reader.

Engine

Neural machine translation

Production version would call a large translation model with glossary constraints and context windows, rather than raw sentence-by-sentence output.

Terminology

Locked glossaries

Per-project term bases enforce approved product names and phrasing. Terms that appear in the base can never drift across languages or releases.

Quality

Human-in-the-loop review

Automation drafts; people decide. The review UI keeps editors in control of final wording, and their edits feed back into the glossary.

Formats

Structure-safe round trips

Translations are re-inserted into the original document tree. Tags and placeholders are validated before export, never after release.

Scripts

RTL & CJK handling

Arabic and Hebrew outputs carry direction metadata for the UI layer; CJK outputs enforce full-width punctuation and locale-appropriate line breaking.
